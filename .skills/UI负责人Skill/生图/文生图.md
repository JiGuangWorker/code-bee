# 文生图（Text-to-Image）

> 从文字描述生成图片。支持两种模型：`z-image-turbo`（快速原型）和 `wan2.7-image-pro`（高质量）。当设计稿缺少配图、图标、插图、背景等素材时使用。

---

## 角色行为

根据设计需求，将文字描述转化为图片素材。

- 快速验证构图/风格 → `z-image-turbo`
- 最终交付素材 → `wan2.7-image-pro`

---

## API 规格

### 端点

```
POST https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation
```

### 认证

```
Authorization: Bearer $DASHSCOPE_API_KEY
```

## 模型一：z-image-turbo（快速原型）

```bash
curl --location 'https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation' \
--header 'Content-Type: application/json' \
--header "Authorization: Bearer $DASHSCOPE_API_KEY" \
--data '{
    "model": "z-image-turbo",
    "input": {
        "messages": [{
            "role": "user",
            "content": [{ "text": "<画面描述>" }]
        }]
    },
    "parameters": {
        "prompt_extend": false,
        "size": "1120*1440"
    }
}'
```

**参数：**

| 参数 | 说明 |
|------|------|
| `prompt_extend` | 是否自动扩展 prompt。建议 `false`，精确控制 |
| `size` | `宽*高` 格式，如 `1120*1440`、`1024*1024` |

**常用尺寸：**

| 用途 | 尺寸 |
|------|------|
| 移动端全屏 | `1120*1440` |
| 方形头像 | `1024*1024` |
| PC Banner | `1920*600` |
| 横版配图 | `1440*810` |
| 竖版海报 | `1080*1920` |

## 模型二：wan2.7-image-pro（高质量）

```bash
curl --location 'https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation' \
--header 'Content-Type: application/json' \
--header "Authorization: Bearer $DASHSCOPE_API_KEY" \
--data '{
    "model": "wan2.7-image-pro",
    "input": {
        "messages": [{
            "role": "user",
            "content": [{ "text": "一间有着精致窗户的花店，漂亮的木质门，摆放着花朵" }]
        }]
    },
    "parameters": {
        "size": "2K",
        "n": 1,
        "watermark": false,
        "thinking_mode": true
    }
}'
```

**参数：**

| 参数 | 说明 |
|------|------|
| `size` | 预设名：`1024*1024`、`2K`、`4K` |
| `n` | 生成数量，默认 1 |
| `watermark` | 是否添加水印，建议 `false` |
| `thinking_mode` | 深度推理模式，质量更高但更慢 |

## 响应体

```json
{
    "output": {
        "choices": [{
            "message": {
                "content": [{ "image": "https://dashscope.aliyuncs.com/..." }]
            }
        }]
    }
}
```

- `n > 1` 时 `choices` 数组包含多张图片

## Prompt 编写规范

### 通用结构

```
[风格/质感关键词]，[镜头/构图描述]。[主体描述]，[场景描述]。
[主体细节：外貌/姿态/服装等]。
[环境细节：背景/光线/色彩]。
```

### 原则

- **风格前置**：开篇声明画风、质感（如 `film grain, photorealistic, Kodak Portra 400 style`）
- **主体明确**：清晰描述画面核心元素
- **细节分层**：从整体到局部逐步细化（姿态 → 面部 → 服装 → 背景 → 光线）
- **避免歧义**：不用模糊词（如「好看的」「漂亮的」），改用具体描述

### 示例

```
film grain, analog film texture, soft film lighting, Kodak Portra 400 style, cinematic grainy texture, photorealistic details, subtle noise, (film grain:1.2)。采用近景特写镜头拍摄的东亚年轻女性，呈现户外雪地场景。她体型纤瘦，呈站立姿势，身体微微向右侧倾斜，头部抬起看向画面上方，姿态自然放松。她的面部是典型东亚长相，肤色白皙，脸颊带有自然的红润感，五官清秀。服装是蓝白拼接的厚重外套，适合雪地环境。背景是被白雪覆盖的户外场景，光线是强烈的自然日光，色调以蓝、白、黑为主，整体风格清新自然。
```

## 故障处理

| 问题 | 处理方式 |
|------|----------|
| `401` | 检查 `DASHSCOPE_API_KEY` |
| `429` | 等待 5-10 秒重试 |
| 风格不符 | 补充风格关键词重新生成 |
| 内容偏离 | 简化 prompt，减少歧义描述 |
