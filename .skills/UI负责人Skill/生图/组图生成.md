# 组图生成（Sequential Generation）

> 基于 `wan2.7-image-pro`，一次生成多张图片，且自动保持主体特征（角色/场景/风格）前后一致。当需要同一角色的多场景展示、故事板、产品多角度视图时使用。

---

## 角色行为

根据包含多个场景的文字描述，生成一组主体一致的连续图片。关键参数是 `enable_sequential: true`。

---

## API 规格

### 端点

```
POST https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation
```

### 认证

```
Authorization: Bearer $DASHSCOPE_API_KEY
```

### 模型

`wan2.7-image-pro`

---

## 请求示例

```bash
curl --location 'https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation' \
--header 'Content-Type: application/json' \
--header "Authorization: Bearer $DASHSCOPE_API_KEY" \
--data '{
    "model": "wan2.7-image-pro",
    "input": {
        "messages": [{
            "role": "user",
            "content": [{
                "text": "电影感组图，记录同一只流浪橘猫，特征必须前后一致。第一张：春天，橘猫穿梭在盛开的樱花树下；第二张：夏天，橘猫在老街的树荫下乘凉避暑；第三张：秋天，橘猫踩在满地的金色落叶上；第四张：冬天，橘猫在雪地上走留下足迹。"
            }]
        }]
    },
    "parameters": {
        "enable_sequential": true,
        "n": 4,
        "size": "2K"
    }
}'
```

**参数：**

| 参数 | 说明 |
|------|------|
| `enable_sequential` | **必须设为 `true`**，启用序列一致性 |
| `n` | 生成数量，与 prompt 中描述的场景数对应 |
| `size` | 预设名：`1024*1024`、`2K`、`4K` |

> ⚠️ `enable_sequential` 不设为 `true` 时，`n > 1` 只生成多张独立图片，不保证主体一致。

---

## 响应体

`n` 张图片，`choices` 数组包含对应数量：

```json
{
    "output": {
        "choices": [
            { "message": { "content": [{ "image": "https://..." }] } },
            { "message": { "content": [{ "image": "https://..." }] } },
            ...
        ]
    }
}
```

---

## Prompt 编写要点

1. **开头声明一致性**：「特征必须前后一致」「保持同一主体」「同一角色，不同场景」
2. **用序号分隔**：「第一张：…」「第二张：…」…使 AI 明确每张对应哪个场景
3. **每张完整描述**：主体 + 环境 + 动作 + 氛围，不可只写场景不含主体

**示例结构：**

```
[风格描述]，[主体一致性声明]。
第一张：[主体]在[场景A]，[动作/姿态]，[环境细节]；
第二张：[同一主体]在[场景B]，[动作/姿态]，[环境细节]；
...
第N张：[同一主体]在[场景N]，[动作/姿态]，[环境细节]。
```

---

## 故障处理

| 问题 | 处理方式 |
|------|----------|
| 主体不一致 | 确认 `enable_sequential: true`，prompt 中强调「特征必须前后一致」 |
| 场景数量不对 | `n` 值与 prompt 中场景数不匹配，调整一致 |
| 某张质量差 | 单独用文生图重新生成该场景 |
