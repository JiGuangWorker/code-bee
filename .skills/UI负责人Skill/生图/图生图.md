# 图生图（Image-to-Image）

> 基于快手 Kling（可灵）`kling-v3-omni-image-generation` 模型，用参考图 + 文字描述生成新图片。支持风格参考、背景参考等多图引导模式，生成结果可保持序列一致性。当需要基于现有图片的风格/构图生成新图、或需要风格迁移时使用。**异步模式**，需轮询获取结果。

---

## 角色行为

根据参考图片和文字描述，生成融合参考图风格/元素的新图片。核心特点：

- **风格参考**：参考图1的风格（色调、笔触、质感）应用于生成结果
- **背景/元素参考**：参考图2的背景或构图元素融入生成结果
- **序列一致性**：`result_type: "series"` 时，`n > 1` 的多张结果保持视觉一致

---

## API 规格

### 端点

```
POST https://dashscope.aliyuncs.com/api/v1/services/aigc/image-generation/generation
```

### 认证

```
Authorization: Bearer $DASHSCOPE_API_KEY
```

### 异步模式

必须带异步 Header：

```
X-DashScope-Async: enable
```

### 模型

`kling/kling-v3-omni-image-generation`

---

## 请求示例

```bash
curl --location 'https://dashscope.aliyuncs.com/api/v1/services/aigc/image-generation/generation' \
--header 'X-DashScope-Async: enable' \
--header "Authorization: Bearer $DASHSCOPE_API_KEY" \
--header 'Content-Type: application/json' \
--data '{
    "model": "kling/kling-v3-omni-image-generation",
    "input": {
        "messages": [{
            "role": "user",
            "content": [
                { "text": "参考图1的风格和图2的背景，生成番茄炒蛋" },
                { "image": "https://example.com/style_ref.png" },
                { "image": "https://example.com/bg_ref.webp" }
            ]
        }]
    },
    "parameters": {
        "n": 4,
        "result_type": "series",
        "aspect_ratio": "1:1",
        "resolution": "1k"
    }
}'
```

**参数：**

| 参数 | 说明 |
|------|------|
| `input.messages[].content[].text` | 生成描述，可用「参考图1」「参考图2」引用图片 |
| `input.messages[].content[].image` | 参考图片 URL（公网可访问），按出现顺序编号 |
| `parameters.n` | 生成数量，默认 1 |
| `parameters.result_type` | `"series"` = 多张结果保持一致性；`"single"` = 独立生成 |
| `parameters.aspect_ratio` | 宽高比：`"1:1"`、`"16:9"`、`"9:16"`、`"4:3"`、`"3:4"` |
| `parameters.resolution` | 分辨率：`"1k"`（标准）、`"2k"`（高清） |

---

## content 数组结构

与 wan2.7 图像编辑不同，Kling 的 content 中 `text` 必须放在第一位，后面的 `image` 按顺序编号：

```json
"content": [
    { "text": "参考图1的风格和图2的背景，生成XXX" },   // text 在前
    { "image": "https://..." },                        // 参考图1
    { "image": "https://..." }                         // 参考图2
]
```

> ⚠️ 与 wan2.7 的关键区别：Kling 要求 `text` 在 content 数组首位，wan2.7 则顺序任意。

## 异步响应与轮询

### 第一步：提交任务

```json
{
    "output": {
        "task_id": "xxx",
        "task_status": "PENDING"
    }
}
```

### 第二步：轮询

```
GET https://dashscope.aliyuncs.com/api/v1/tasks/{task_id}
Authorization: Bearer $DASHSCOPE_API_KEY
```

### 第三步：获取结果

```json
{
    "output": {
        "task_id": "xxx",
        "task_status": "SUCCEEDED",
        "results": [
            { "url": "https://..." },
            { "url": "https://..." },
            ...
        ]
    }
}
```

`n = 4` 时 `results` 数组包含 4 个 URL。`result_type: "series"` 时这 4 张图视觉风格一致。

## 与 wan2.7 图像编辑的区别

| 能力 | 图生图（Kling） | 图像编辑（wan2.7） |
|------|:--:|:--:|
| 端点 | `/image-generation/generation` | `/multimodal-generation/generation` |
| 模型 | `kling/kling-v3-omni` | `wan2.7-image-pro` |
| 模式 | 异步 | 同步 |
| content 顺序 | text **必须**在首位 | text 顺序任意 |
| 参考图作用 | 风格/背景/构图参考 | 合成素材（直接拼合） |
| 精确定位 | ❌ 无 bbox | ✅ bbox_list |
| 序列一致性 | ✅ `result_type: "series"` | ❌ |
| 尺寸控制 | `aspect_ratio` + `resolution` | `size` 预设名 |
| 典型场景 | 风格迁移、参考图生成 | 多图合成、元素替换 |

## 适用场景

| 场景 | 说明 |
|------|------|
| 风格迁移 | 参考图1提供风格，生成不同内容但同风格的图 |
| 背景替换 | 参考图2提供背景，生成主体在新背景中的图 |
| 产品多角度 | 参考产品图，生成同一产品的不同角度 |
| 设计变体 | 参考设计稿，生成不同配色/布局的变体 |
| 系列化素材 | `result_type: "series"` 一次生成风格统一的 n 张图 |

---

## Prompt 编写要点

- **text 放在首位**，后面跟 image 列表
- 明确每个参考图的用途：「参考图1的风格」「参考图2的背景」
- 描述生成目标：主体是什么、放在什么场景中
- 示例结构：

```
参考图1的[风格/色调/质感]和图2的[背景/构图/元素]，生成[目标内容]，[补充细节要求]
```

---

## 故障处理

| 问题 | 处理方式 |
|------|----------|
| 生成结果忽略参考图 | prompt 中更明确地指定参考图用途（如「严格使用图1的色调」） |
| 风格迁移不准确 | 参考图选择与目标风格更匹配的图片 |
| content 顺序导致报错 | 确保 text 在 content 数组第一位 |
| `task_status` 始终 `PENDING` | Kling 推理时间可能较长（30s-120s），继续轮询 |
| `resolution` 参数无效 | 确认值为 `"1k"` 或 `"2k"` |
