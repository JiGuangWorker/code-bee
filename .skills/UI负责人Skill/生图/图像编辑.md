# 图像编辑（Image Editing）

> 基于 `wan2.7-image-pro`，用参考图片 + 文字指令进行合成编辑。支持两种模式：**基本编辑**（多图合成）和**交互式编辑**（bbox 精确定位）。当需要给产品换背景、合成元素到场景中、或将元素精确放置到指定位置时使用。

---

## 角色行为

根据参考图和文字指令，合成或编辑图片。核心原则：

- 参考图 URL 必须公网可访问
- content 中的图片按顺序编号为「图1」「图2」…文字指令中用图号引用
- 需要精确定位时使用 bbox 模式，不需要时用基本模式

### 端点

### 模型

`wan2.7-image-pro`

## 模式一：基本编辑（多图合成）

提供多张参考图片 + 文字描述，AI 理解图片内容后按指令合成。

```bash
curl --location 'https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation' \
--header 'Content-Type: application/json' \
--header "Authorization: Bearer $DASHSCOPE_API_KEY" \
--data '{
    "model": "wan2.7-image-pro",
    "input": {
        "messages": [{
            "role": "user",
            "content": [
                { "image": "https://example.com/car.webp" },
                { "image": "https://example.com/paint.webp" },
                { "text": "把图2的涂鸦喷绘在图1的汽车上" }
            ]
        }]
    },
    "parameters": {
        "size": "2K",
        "n": 1,
        "watermark": false
    }
}'
```

**content 数组规则：**

| 元素 | 格式 | 说明 |
|------|------|------|
| `image` | `{"image": "<公网可访问的图片URL>"}` | 参考图，按出现顺序编号为「图1」「图2」… |
| `text` | `{"text": "<编辑指令>"}` | 描述合成方式，用「图N」指代图片 |

> `image` 和 `text` 在 content 中的顺序任意，但 text 中引用的图号按 image 的出现顺序编号。

**参数：**

| 参数 | 说明 |
|------|------|
| `size` | 预设名：`1024*1024`、`2K`、`4K` |
| `n` | 生成数量，默认 1 |
| `watermark` | 是否添加水印，建议 `false` |

## 模式二：交互式编辑（bbox 精确定位）

在基本编辑基础上，通过 `bbox_list` 参数指定目标图片上的放置区域。

```bash
curl --location 'https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation' \
--header 'Content-Type: application/json' \
--header "Authorization: Bearer $DASHSCOPE_API_KEY" \
--data '{
    "model": "wan2.7-image-pro",
    "input": {
        "messages": [{
            "role": "user",
            "content": [
                { "image": "https://example.com/clock.webp" },
                { "image": "https://example.com/scene.webp" },
                { "text": "把图1的闹钟放在图2的框选的位置，保持场景和光线融合自然" }
            ]
        }]
    },
    "parameters": {
        "bbox_list": [
            [],
            [[989, 515, 1138, 681]]
        ],
        "size": "2K",
        "n": 1,
        "watermark": false
    }
}'
```

**`bbox_list` 说明：**

```
bbox_list: [
    [],                                  // 图1：空数组 = 保留整张图
    [[x1, y1, x2, y2], [...]],          // 图2：bbox 区域列表
    ...
]
```

- `bbox_list` 与 content 中的 `image` 按顺序一一对应
- 空数组 `[]` = 不裁剪，保留完整
- `[[x1, y1, x2, y2]]` = 一个矩形区域，`(x1,y1)` 左上角，`(x2,y2)` 右下角
- 典型用法：图A（源元素）bbox 为空，图B（目标场景）bbox 为放置区域

## Prompt 编写要点

- 用「图1」「图2」指代参考图片
- 指令简洁明确：「把图1的XX放在图2的XX位置」
- 补充融合要求：「保持场景和光线融合自然」「保持图1的质感」
- bbox 模式下：text 描述整体意图 + bbox 指定精确位置

---

## 故障处理

| 问题 | 处理方式 |
|------|----------|
| 合成不自然 | text 中补充融合要求（光线、质感、透视一致） |
| 位置不准 | 调整 `bbox_list` 坐标值 |
| 参考图无法识别 | 确认 URL 公网可访问，图片格式为常见格式（webp/jpg/png） |
| `401` / `429` | 同上 |
